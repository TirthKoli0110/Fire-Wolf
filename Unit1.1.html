Concept of WWW (World Wide Web)

World Wide Web (WWW) is a system of interconnected web pages and information that can be accessed through the internet.

Main Components:

  • URL (Uniform Resource Locator):

    Address of a webpage.
    Example: (https://www.example.com/)

  • HTTP (Hyper Text Transfer Protocol):

    Rules used for communication between a web browser and web server.

  • HTML (Hyper Text Markup Language):

    Language used to create and structure webpages, such as text, images, and links.

Internet vs WWW

  • Internet:

    Global network connecting and devices.

  • WWW:

    A service/application that runs on top of the internet and provides webpages and web content.
