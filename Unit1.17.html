Web Technology

WWW

WWW = Collection of interconnected webpages accessed through the Internet.

Internet

Internet = Global network of connected computers/devices.

URL

URL = Address of a webpage.

HTTP

HTTP = Protocol used for communication between browser and server.

HTML

HTML = Language used to structure webpages.

Browser

Browser = Client that requests and displays webpages.

Web Server

Web Server = Receives requests and provides web resources.

Web 2.0

Web 2.0 = Interactive, social and user-generated Web.

Static IP

Static IP = Fixed IP address.

Dynamic IP

Dynamic IP = Automatically assigned IP that may change.

Effective Web Design

Effective Web Design = Simple + Fast + Easy to navigate + User-focused.
