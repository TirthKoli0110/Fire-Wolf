Features of Web 2.0

  1. Folksonomy

    2. Users can create their own classifications or tags for information.
    Examples: Flickr and Delicious.

  2. Rich User Experience

    3. Websites provide interactive and dynamic experiences using technologies such as AJAX, CSS and HTML5.
    Examples:

    • Google Maps
    • Google Suggest

    Key idea:
    Users can interact with webpages instead of simply reading them.

  3. Long Tail

    4. Instead of focusing only on popular products/services, Web 2.0 can provide many niche products and services to users.
    Examples:Google Apps and CRM services.

  4. User Participation

    5. Users contribute and create content themselves.
    This is also called crowdsourcing.

    • Wikipedia
    • YouTube

  5. Basic Trust

    6. Traditional Web content may be protected by intellectual property rights, while Web 2.0 encourages content to be shared, reused and redistributed under appropriate permissions.
    Examples: Creative Commons.

  6. Dispersion

    7. Content can be distributed through multiple channels rather than being available only on one website.
    Examples:

    • BitTorrent
    • Mashups
