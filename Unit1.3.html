Internet

The Internet is a worldwide network of interconnected computers and devices.

Features:

  • Connects millions of computers worldwide.
  • Allows data transfer and communication.
  • Provides services such as:
    • Email
    • File Transfer
    • Remote login
    • Web browsing
  • Uses TCP/IP protocols for communication.
  • It is decentralized, meaning there is no single central authority controlling the entire Internet.
  • Internet connectivity is provided by ISPs (Internet Service Providers).

In simple words:
Internet = Network of networks
