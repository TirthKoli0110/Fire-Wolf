Dynamic IP Address

A Dynamic IP address is assigned automatically and can change over time.
It is commonly assigned using DHCP (Dynamic Host Configuration Protocol).

Features:

  • Automatically assigned.
  • Can change periodically.
  • Useful for normal devices and temporary connections.
  • Helps efficient use of available IP addresses.

Example:192.168.0.101
192.168.0.102

Remember:
Dynamic IP = Automatically assigned + may change
