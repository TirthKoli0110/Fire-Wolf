WWW

The World Wide Web is an application that operates using the Internet.

Important points:

  • Provides a user-friendly way to access information.
  • Allows users to access:
    • Websites
    • Webpages
    • Images
    • Videos
    • Other multimedia
  • Uses hyperlinks to connect webpages.
  • Uses HTTPfor communication between web browsera and web pages.
  • Follows the client-server model.
  • Web browsers act as clients and web servers provide requested content.

Remember:
Internet is the infrastructure; WWW is a service running on that infrastructure.
