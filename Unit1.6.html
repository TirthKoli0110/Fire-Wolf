HTTP Response

The server sends an HTTP Response back to the browser.

Main parts:

  1. Status Code

    2. Tells whether the request was successful.
    Examples:

    • 200 OK → Request successful
    • 404 Not Found → Resource not found
    • 500 Internal Server Error → Server error
  2. Response Headers

    3. Contain additional information about the response.

  3. Response Body

    4. Contains the actual content/data sent by the server, such as HTML code.

Simple example:

Browser → HTTP Request → Server
Browser ← HTTP Response ← Server
