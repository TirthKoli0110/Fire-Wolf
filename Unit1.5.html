HTTP

HTTP = HyperText Transfer Protocol

It is a communication protocol used between web browsers and web servers.

When you visit a website:

  • Browser → sends HTTP Request
  • Server → sends HTTP Response

HTTP Request

An HTTP request contains information such as:

  1. HTTP Version

    2. Specifies the HTTP version being used.
    Example: HTTP/1.1

  2. HTTP Method

    3. Specifies what action is required.
    Common methods:

    • GET – retrieve data
    • POST – send data to the server
  3. Request Headers

    4. Provide additional information about the request, such as browser type and content type.

  4. Request Body

    5. Contains data sent to the server, commonly when submitting a form.
