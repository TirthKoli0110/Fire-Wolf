Working of WWW

The WWW follows a client-server model.

Working process:

  1. User enters a website address in a web browser.
  2. Browser sends an HTTP Request to the web server.
  3. Web server processes the request.
  4. Server sends an HTTP Response containing the requested webpage/data.
  5. Browser displays the webpage to the user.

Simple flow:

User → Web Browser → HTTP Request → Web Server
User ← Web Browser ← HTTP Response ← Web Server
