Web 2.0

Web 2.0 refers to the modern, interactive and social form of the Web.
Unlike the older web, where users mainly read information, Web 2.0 allows users to read, write and interact.

Main features:

  • User-generated content
  • Interaction
  • Collaboration
  • Social networking
  • Sharing
  • Comments
  • Uploading content
  • Connecting with other users

Easy definition:
Web 2.0 = Interactive and social Web
