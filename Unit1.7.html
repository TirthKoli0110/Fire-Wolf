Web Browser

A web browser is software used to access and display webpages on the Internet.

Examples:

  • Google Chrome
  • Mozilla Firefox
  • Safari
  • Microsoft Edge

Functions:

  • Sends requests to web servers.
  • Receives HTTP responses.
  • Displays webpages.
  • Provides an interface between the user and web server.
  • Stores information such as cookies locally.
  • Allows users to access websites and online services.

Important:
Browser = Client
