Web Server

A web server is a computer/software system that stores and delivers web content to clients.

Functions:

  • Receives HTTP requests.
  • Processes requests.
  • Finds the required webpage/resource.
  • Sends HTTP responses to browsers.
  • Stores website resources.
  • Hosts websites.

Processing models:

  • Process-based
  • Thread-based
  • Event-based

Example:
Apache Server

Important:
Web Server = Provides requested web resources
